# Whiteboard cloud icons

Official architecture icons shown in the whiteboard's component panel (AWS and Azure tabs), one SVG per icon,
listed with their categories in `index.json` here, which the panel loads at runtime. Both are generated by
`scripts/import-cloud-icons.py`.

**They are not in the repository.** Their licences allow using them to create architecture diagrams, not
republishing the icon sets, so this folder is git-ignored apart from this README. Until you import them, the AWS and
Azure tabs show how to add them; the Core components work regardless. To add them:

1. Download and unzip the AWS **Icon package** from https://aws.amazon.com/architecture/icons/ and the
   **Azure Public Service Icons** from https://learn.microsoft.com/azure/architecture/icons/.
2. From `frontend/`, run `python3 -I scripts/import-cloud-icons.py <unzipped AWS dir> <unzipped Azure dir>`.
3. Reload the app.

- `aws/`: **AWS Architecture Icons**, Icon package 07/31/2026 (service icons at 48 px, resource icons in their light
  variant, group icons), from https://aws.amazon.com/architecture/icons/. AWS permits customers and partners to use
  them to create architecture diagrams.
- `azure/`: **Azure Public Service Icons V24**, from https://learn.microsoft.com/azure/architecture/icons/. Microsoft
  permits their use in architectural diagrams, training materials and documentation (Microsoft Terms of Use in the
  package).

The files are copied unchanged. Rerun the script to update to newer packages.
